## 2. Logic Chain

### Logic Chain for R1 (Geographic Filtering Execution Order):
1. **Fact**: `filtrar_chunks_por_localidad` computes geographic relevance (`DIRECTA`, `GENERAL`, `None`) and adjusts `item["score"]` by adding `+0.15` for `DIRECTA` or subtracting `-0.10` for `GENERAL` (Observation 1.2).
2. **Fact**: In `enrich_festival_program` (Observation 1.2), `filtrar_chunks_por_localidad` is called on line 1310 when `item["score"]` is `0.0`. Subsequently, line 1317 assigns `item["score"] = AsyncRAGProcessor.cosine_similarity(...)`.
3. **Inference**: Assigning cosine similarity on line 1317 overwrites `item["score"]`, completely destroying the `+0.15` bonus and `-0.10` penalty calculated on line 1310.
4. **Fact**: `seleccionar_chunks` (Observation 1.1) calls `filtrar_chunks_por_localidad` internally. Coupling geographic filtering inside budget-packing logic mixes two separate architectural concerns (geographic re-ranking vs. budget/source quota selection).
5. **Conclusion for R1**: Geographic filtering (`filtrar_chunks_por_localidad`) must be removed from `seleccionar_chunks` and called explicitly AFTER similarity score computation in all retrieval pipelines (`discover_festivals_for_locality`, `retrieve_discovery_context`, `enrich_festival_program`, and `saturate_context_docs`).

### Logic Chain for R3 (Embedding Target Text):
1. **Fact**: In `index_document_chunks` (Observation 1.3), line 1106 passes `i["chunk_contextualizado"]` to `get_embeddings_batch`.
2. **Fact**: `i["chunk_contextualizado"]` includes artificial metadata warnings and URLs generated by `generar_cabecera_chunk` (e.g. `[FUENTE: Web oficial ... | AVISO: ...]`).
3. **Inference**: Dense embedding models (e.g., `text-embedding-nomic-embed-text-v1.5`) encode the semantic weight of these artificial header tokens, creating vector noise that skews similarity distance away from actual festival event data.
4. **Conclusion for R3**: `index_document_chunks` line 1106 must use raw `i["chunk"]` instead of `i["chunk_contextualizado"]` when creating `chunks_text` for embedding generation.

## 4. Conclusion

- **Requirement R1**: `llm_processor/text_analyzer.py` requires refactoring `seleccionar_chunks` to remove the embedded call to `filtrar_chunks_por_localidad`, and updating `discover_festivals_for_locality`, `retrieve_discovery_context`, and `enrich_festival_program` so that `filtrar_chunks_por_localidad` is invoked explicitly after cosine similarity is assigned to `item["score"]`.
- **Requirement R3**: `llm_processor/text_analyzer.py` requires updating line 1106 in `index_document_chunks` from `chunks_text = [i["chunk_contextualizado"] for i in items]` to `chunks_text = [i["chunk"] for i in items]`.
